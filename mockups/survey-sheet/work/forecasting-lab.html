Forecasting Lab

In progress

Can a pre-trained time-series model beat a tuned baseline on traffic sensors?

At short horizons a tuned gradient boosting model is hard to beat. Past one hour, Chronos, used with no tuning at all, has the lowest error, about 18% below the seasonal baseline at two hours.

Method

  1. Split the data chronologically into train, validation and test, with no overlap.
  2. Fit scalers on the training data only.
  3. Build the seasonal naive baseline from the same weekday last week.
  4. Tune gradient boosting and the GRU on validation data only, and run Chronos zero-shot.
  5. Score every model on the same test window.

Limitations

  • One dataset from one city.
  • Chronos's context length caps how much history it sees.
  • No exogenous features such as weather or holidays.
  • MAE hides rare congestion spikes.
