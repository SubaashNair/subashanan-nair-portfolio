LLM Eval Lab

How well do small and frontier models handle Bahasa Malaysia and Manglish?

The answer

On Manglish sentiment, a fine-tuned 1B model lands within 3 points of a frontier model at about a fiftieth of the cost. On summaries, the frontier model still leads clearly.

Key numbers

3 points

gap between the fine-tuned 1B and the frontier model on sentiment.

The 95% intervals overlap, so the gap could be smaller.

1/50th

the cost per 1k items for the fine-tuned 1B.

List prices on the run date; prices change.

1,200

hand-labelled items per task.

Inter-annotator agreement was 0.81 on a 20% overlap.

How it was made

Method

  1. Write and freeze the labelling guidelines.
  2. Label 1,200 items per task, with a second annotator on 20%.
  3. Version prompts (v1 to v3) in the repo.
  4. Run each model 3 times at temperature 0, recording cost and latency per call.
  5. Bootstrap 95% intervals for every score.

Limitations

  • Manglish varies by region and age; one set cannot cover it.
  • Inter-annotator agreement was 0.81, not perfect.
  • Frontier model versions change, so results are dated.
  • Costs use list prices on the run date.
