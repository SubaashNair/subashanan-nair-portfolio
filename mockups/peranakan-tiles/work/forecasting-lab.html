Forecasting Lab

Can a pre-trained time-series model beat a tuned baseline on traffic sensors?

The answer

At short horizons a tuned gradient boosting model is hard to beat. Past one hour, Chronos, used with no tuning at all, has the lowest error, about 18% below the seasonal baseline at two hours.

Key numbers

18%

lower error for Chronos than the seasonal baseline at 2 hours.

Interval 12 to 23%, from a bootstrap over test days.

4

models compared on the same chronological splits.

One dataset from one city, so treat the ranking as local.

0

Its context length still caps how much history it sees.

Method

  1. Split the data into chronological train, validation and test windows with no overlap, and fit scalers on training data only.
  2. Build the seasonal naive baseline from the same weekday last week.
  3. Tune gradient boosting and the GRU on the validation window only.
  4. Run Chronos zero-shot, with no tuning.
  5. Score every model on the same test window at each horizon.

Limitations

  • One dataset from one city.
  • Chronos context length caps how much history it sees.
  • No exogenous features like weather or holidays.
  • MAE hides rare congestion spikes, which matter most to drivers.
