Forecasting Lab

Can a pre-trained time-series model beat a tuned baseline on traffic sensors?

In progress

Short answer

At short horizons a tuned gradient boosting model is hard to beat. Past one hour, Chronos, used with no tuning at all, has the lowest error, about 18% below the seasonal baseline at two hours.

Method

  1. Split the data chronologically into train, validation and test windows with no overlap.
  2. Fit scalers on training data only.
  3. Build the seasonal naive baseline from the same weekday last week.
  4. Tune gradient boosting and the GRU on validation only, and run Chronos zero-shot.
  5. Score every model on the same test window at 15, 30, 60, 90 and 120 minutes.

Limitations

  • One dataset from one city, so the ranking may not hold elsewhere.
  • The Chronos context length caps how much history it sees.
  • No exogenous features such as weather or holidays.
  • MAE hides rare congestion spikes, which matter most to drivers.
