LLM Eval Lab

How well do small and frontier models handle Bahasa Malaysia and Manglish?

Planned

Short answer

On Manglish sentiment, a fine-tuned 1B model lands within 3 points of a frontier model at about a fiftieth of the cost. On summaries, the frontier model still leads clearly.

Method

  1. Write and freeze the labelling guidelines before labelling starts.
  2. Label 1,200 items per task, with a second annotator on 20%.
  3. Version the prompts (v1 to v3) in the repo.
  4. Run each model 3 times at temperature 0 and bootstrap 95% intervals.
  5. Record cost and latency for every call.

Limitations

  • Manglish varies by region and age, and one set cannot cover it.
  • Inter-annotator agreement was 0.81, not perfect.
  • Frontier model versions change, so these results are dated.
  • Costs use list prices on the run date.
